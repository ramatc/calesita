# Calesita

Party games for friends in the same room, moderated by one shared device. No sign-up, no download.

## Run it

```bash
pnpm install
pnpm dev
```

Then open <http://localhost:3000>.

## Characters

The seven characters live in `public/characters`. See `public/characters/README.md` to replace the art or add expressions and poses.

## Checks

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```
