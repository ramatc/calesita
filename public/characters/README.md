# Character art

Each character has one folder, named after its `id` in `src/content/characters.ts`.

| File | Use | Canvas |
| --- | --- | --- |
| `portrait.svg` | Avatars, on the character's color | Square, transparent |
| `full.svg` | Full-body lineup on the home | 260 × 420, transparent, feet on the same ground line |

`sheet.svg` shows all seven together. It is the place to judge consistency.

## Current art

These files are generated by `pnpm characters:build` from a shared rig in `scripts/characters/`. Every character is the same drawing with different parameters.

## Replace the art

1. Export every character from one joint sheet, on the same canvas and ground line.
2. Save them over the files above. For PNG, also change the extension in `src/content/characters.ts`.
3. Stop using `pnpm characters:build`, which would overwrite them.

If a file is missing, the avatar shows the character's initial on its color.

## Add an expression or pose

- Expression: add the file, then add it to the character's `art.variants`, for example `"portrait-celebrating": "/characters/rama/portrait-celebrating.png"`. Screens already ask for `celebrating` and `sad`; until the art exists they get the base portrait.
- New expression or pose name: add it to `CharacterExpression` or `CharacterView` in `src/types/character.ts`.
